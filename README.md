# Aqua Flora

Aqua Flora is a static website for a company focused on hydroponics and AgriTech solutions.

## Features

- Responsive layout for desktop and mobile
- Product, company, news, and contact sections
- French, English, and Arabic language switcher
- Hydroponic solutions showcase

## Run locally

No installation is required. Open `main.html` in a web browser.

You can also start a simple local server:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Project structure

- `main.html` - website markup, styles, and scripts
- `assets/` - images used by the website
